# Code Basics ML Practice Repository

Welcome to my Machine Learning practice repo! This repository contains my hands-on exercises and notebooks from following the excellent Machine Learning tutorials on the [Code Basics YouTube channel](https://www.youtube.com/c/codebasics). I created this as a way to learn ML step-by-step through weekly practices, starting from the basics and progressing to more advanced topics.

If you're new to Machine Learning or looking to brush up on concepts with practical examples, this repo can be a great resource. Each week focuses on a specific theme, with Jupyter notebooks demonstrating key ideas, code implementations, and exercises. Feel free to clone it, run the notebooks, and experiment yourself!

## Why This Repo is Useful for Learning ML
- **Structured Learning Path**: Organized into weekly modules, making it easy to follow along progressively.
- **Hands-On Practice**: Real code examples and exercises to reinforce theoretical concepts.
- **From Basics to Advanced**: Covers foundational topics like data handling and moves into algorithms like classification, clustering, and optimization.
- **Inspired by Code Basics**: Based on clear, beginner-friendly tutorials – perfect for self-learners.

## Repository Structure
The repo is divided into weekly directories, each focusing on a key ML concept. Here's an overview:

- **week_1**: Introduction to ML basics (likely setup, simple models, or data exploration).
- **week_2**: Building on fundamentals (possibly more data manipulation or introductory algorithms).
- **week_3**: Intermediate concepts (e.g., feature engineering or basic predictions).
- **week_4_pickle**: Model serialization using Pickle (saving and loading ML models).
- **week_5**: Further model development or evaluation techniques.
- **week_6_split**: Data splitting methods (train-test split for model validation).
- **week_7_classi**: Binary classification algorithms.
- **week_8_multi_classification**: Handling multi-class classification problems.
- **week_9_decision_tree**: Decision Tree models and their applications.
- **week_10_svm**: Support Vector Machines (SVM) for classification and regression.
- **week_11_random_forest**: Ensemble methods with Random Forests.
- **week_12_k_fold_cross_valid**: K-Fold Cross-Validation for robust model assessment.
- **week_13_clustering**: Unsupervised learning with clustering algorithms (e.g., K-Means).
- **week_14_naive_bayes**: Naive Bayes classifiers for probabilistic modeling.
- **weel_15_hyper**: Hyperparameter tuning (optimizing model parameters for better performance). *(Note: This folder name has a typo; it should be "week_15_hyper".)*

Each directory typically contains Jupyter notebooks (.ipynb files) with code, explanations, and practice exercises. There might also be supporting files like datasets or scripts if needed.

## How to Get Started
1. **Clone the Repo**: `git clone https://github.com/afsal4/code_basics_ml.git`
2. **Set Up Environment**: Install Python and required libraries (e.g., via `pip install jupyter numpy pandas scikit-learn`).
3. **Run Notebooks**: Open Jupyter Notebook in a directory (e.g., `jupyter notebook`) and explore the .ipynb files.
4. **Follow Along**: Watch the corresponding Code Basics videos for each week to understand the theory behind the code.

## Prerequisites
- Basic Python knowledge.
- Familiarity with Jupyter Notebooks.
- Libraries: NumPy, Pandas, Scikit-Learn, Matplotlib (install with pip if needed).
